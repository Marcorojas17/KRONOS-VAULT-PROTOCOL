# Brand Usage · Quick Reference

> Quick reference for the permitted and restricted uses of the project
> identifiers. The authoritative policy is [`TRADEMARK.md`](TRADEMARK.md).

```bash
$ ktp brand --cheatsheet
─────────────────────────────────────────────────────────────────
  ✓  YES   factual reference · citation · "compatible with KTP-001"
  ✗  NO    product name · logo use · register as trademark
─────────────────────────────────────────────────────────────────
```

---

## `// 01` — DO

```text
  ┌─[ ALLOWED ]──────────────────────────────────────────────────────┐
  │                                                                  │
  │  ✓  "This product implements the Kronos Vault Protocol (KTP)."  │
  │                                                                  │
  │  ✓  "Compatible with KTP-001 Level 3."                          │
  │                                                                  │
  │  ✓  "Based on the open specification KTP-001."                  │
  │                                                                  │
  │  ✓  "Uses the FVD-(MARCA)-NNNNN folio format defined by KTP."   │
  │                                                                  │
  │  ✓  "See https://github.com/Marcorojas17/kronos-protocol."      │
  │                                                                  │
  └──────────────────────────────────────────────────────────────────┘
```

---

## `// 02` — DON'T

```text
  ┌─[ NOT ALLOWED ]──────────────────────────────────────────────────┐
  │                                                                  │
  │  ✗  "Kronos™ is our product."                                    │
  │                                                                  │
  │  ✗  "Kronos Vault Protocol, brought to you by <company>."        │
  │                                                                  │
  │  ✗  "Official Kronos implementation."                            │
  │                                                                  │
  │  ✗  Using the logo on marketing materials without authorization. │
  │                                                                  │
  │  ✗  "Kronos Cloud" / "KTP Enterprise" as your product name.      │
  │                                                                  │
  │  ✗  Registering "kronos-vault.com" or similar domains.           │
  │                                                                  │
  └──────────────────────────────────────────────────────────────────┘
```

  ┌─[ DECISION TREE ]───────────────────────────────────────────────┐

## `// 06` — LOGO USE

Use of the logo requires written authorization.

If granted, you MUST:

- Use the logo unmodified.
- Maintain the minimum clear space.
- Use only the versions provided in `assets/`.

To request authorization, contact `proyectokronos@hotmail.com`.
