## `// 02` — WHAT IS NOT PROTECTED

The **specification itself** is open. Under CC-BY-4.0, you may:

- Use the format `FVD-(MARCA)-NNNNN` freely.
- Implement the protocol without authorization.
- Modify the specification for your needs.
- Redistribute the specification with attribution.
- State that your implementation is *"compatible with KTP-001"*.

The brand policy does **NOT** restrict implementation. It only restricts
the use of the names and logo to prevent confusion.
