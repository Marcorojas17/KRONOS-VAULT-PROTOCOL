# RFCs · Kronos Vault Protocol

This directory contains the Request for Comments (RFC) documents that
propose, discuss, and record changes to the specification.

## Index

```text
  0000-process.md    Process for proposing and approving changes
  0001-template.md   Template for new RFCs
```

## Status values

| Status | Meaning |
|--------|---------|
| DRAFT | Under discussion |
| PROPOSED | Open for formal review |
| ACCEPTED | Approved, pending implementation |
| FINAL | Part of the specification |
| REJECTED | Not accepted |
| WITHDRAWN | Retracted by author |
| DEPRECATED | Superseded |

## How to file a new RFC

1. Read `0000-process.md`.
2. Copy `0001-template.md` to `NNNN-title.md`.
3. Open an issue and a pull request.
4. Wait for review.
